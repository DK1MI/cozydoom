# CozyDoom WAD Builder

A static web page that builds a custom **CozyDoom** PWAD for Doom II in the browser.

For every Doom II monster you pick a replacement (default: the monster itself) and a
health percentage (of the replacement's normal HP). **Download WAD** produces a WAD with:

| Lump       | Used by | What it does |
|------------|---------|--------------|
| `DEHACKED` | dsda-doom, Woof, Nugget, PrBoom+, Eternity, Crispy (`-dehlump`) | Gives each changed monster slot the replacement's stats, frames, sounds and flags, with the chosen HP |
| `ZSCRIPT`  | GZDoom / UZDoom | `class CZ_X : Replacement replaces X { Health N; }` |
| `ZMAPINFO` | GZDoom / UZDoom | Maps the editor numbers straight to those classes |

Load it last: `gzdoom -iwad doom2.wad -file maps.wad cozydoom.wad`

Details:
* Monsters keep their own item drops (a Zombieman replaced by an Imp still drops a clip).
* Boss-level exits keep working: if the Mancubus, Arachnotron, Baron, Cyberdemon or Spider
  Mastermind is replaced by a monster that doesn't call `A_BossDeath`, the builder adds it
  (DEHACKED: copied death frames in the DEHEXTRA range, so not Chocolate Doom; GZDoom: a `Die` override).
* Replacing the Lost Soul also changes what Pain Elementals spit out.
* Settings are kept in the URL (`#c=...`), so a link shares a configuration.

## Hosting on GitHub Pages

1. Create a repository and push the contents of this folder to it.
2. Repository **Settings → Pages → Build and deployment → Deploy from a branch**, pick `main` and `/ (root)`.
3. The site appears at `https://<user>.github.io/<repo>/`.

No build step: it is plain HTML, CSS and JavaScript.

## Files

* `index.html`, `style.css`, `app.js` – the page
* `wad.js` – DEHACKED / ZSCRIPT / ZMAPINFO generation and the WAD writer
* `data.js` – Doom II monster table, generated by `tools/gen_data.py` from `tools/doom_info.json`

Contains no id Software assets; players need their own `doom2.wad`.
